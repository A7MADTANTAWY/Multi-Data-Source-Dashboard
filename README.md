# Multi-Sales Dashboard

Power BI dashboard project for sales analysis across three main pages:

- Sales Dashboard
- Product Dashboard
- Customer Dashboard

## Project Structure

```text
Multi-Sales-Dashboard/
├── assets/
│   └── icons/
├── data/
├── dashboard/
├── docs/
│   └── screenshots/
├── README.md
└── .gitignore
```

## Files

- `dashboard/Sales Multi Source Data.pbix` - main Power BI report
- `data/` - source Excel databases
- `assets/icons/` - dashboard navigation and UI icons
- `docs/screenshots/` - report page screenshots

## Dashboard Pages

1. Sales Dashboard
2. Product Dashboard
3. Customer Dashboard

## Data Sources

- Customer Database.xlsx
- Product Database.xlsx
- Sales Database.xlsx
